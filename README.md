# Kitab Ghar · کتاب گھر

An interactive 3D bookshelf featuring 24 books from Pakistan, China, India, and world literature.

- Illustrated edition covers, coordinated spines, and native Chinese titles
- Wheel, drag, arrow-key, and category navigation
- Expanded book details and edition links
- Responsive layout and reduced-motion support

## Run locally

Serve this directory with any static web server, for example:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000.

## Deploy

Import this repository into Vercel as **Other**. No build command is required; the output directory is `.`.
